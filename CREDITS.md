# Credits

Skills here were written, adapted, or copied from work by other developers. All upstream
sources are MIT licensed. Where a skill started as someone else's, it is named below.

| Skill | Origin |
| --- | --- |
| `type-driven-development` | Principles adapted from [dmmulroy/skills](https://github.com/dmmulroy/skills), [Makisuo/skills](https://github.com/Makisuo/skills), and [kitlangton/skills](https://github.com/kitlangton/skills) |
| `effect-ts` | Unmodified from [Effect-TS/skills](https://github.com/Effect-TS/skills/tree/main/skills/effect-ts), installed with the skills CLI (see `vendor/skills-lock.json`) |
| `effect-patterns` | Application patterns adapted from [kitlangton/skills](https://github.com/kitlangton/skills), [dmmulroy/skills](https://github.com/dmmulroy/skills), and [Makisuo/skills](https://github.com/Makisuo/skills) |
| `agent-browser` | Unmodified from [vercel-labs/agent-browser](https://github.com/vercel-labs/agent-browser/tree/main/skills/agent-browser), installed with the skills CLI (see `vendor/skills-lock.json`) |
| `testing-principles` | Adapted in our own words from the authoring gate, junk patterns, and audit of [openclaw's test-audit skill](https://github.com/openclaw/openclaw/blob/main/.agents/skills/test-audit/SKILL.md); its writing reference moved from `type-driven-development` |
| `writing-principles` | Informed by the unslop and technical-writing skills in [poteto's pstack](https://github.com/cursor/plugins/tree/main/pstack), the cache and sediment ideas in `writing-for-agents` from [mattpocock/skills](https://github.com/mattpocock/skills), [Diátaxis](https://diataxis.fr/), [Google's timeless documentation](https://developers.google.com/style/timeless-documentation), and [Wikipedia's signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing) |
| `design-engineering` | Emil Kowalski's design engineering and [animations.dev](https://animations.dev/) material |

Except for the unmodified `effect-ts` and `agent-browser`, these are maintained here and do not track upstream.
Effect API truth comes from the installed package's `AGENTS.md`, `ai-docs/`, and source; local
`effect-patterns` adds application-level judgment without copying that manual.
